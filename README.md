# Ерөнхий журналын вэб программ

Жижиг хэмжээний нягтлан бодох бүртгэлийн вэб программ. Зөвхөн ерөнхий журналыг хөтлөх, тайлан үзэх, дансны жагсаалтаа удирдах боломжтой.

## Тойм

- Нэг файлд багтсан HTML программ (`index.html`) — серверийн тохиргоо хэрэггүй, хөтчөөр шууд нээж ажиллуулна.
- Цайвар, цэвэрхэн дизайн (саарал/цагаан өнгө аяс).
- Бүх өгөгдөл хөтчийн `localStorage`-д хадгалагдана.

## Шаардлага (Requirements)

Захиалагчийн хүсэлтээр дараах шаардлагуудыг хэрэгжүүлсэн:

### R1. Ерөнхий шаардлага
- **R1.1** Маш жижиг хэмжээний нягтлан бодох бүртгэлийн вэб программ байх.
- **R1.2** Цайвар, цайвар өнгө аяс (цагаан/саарал) ашиглах.
- **R1.3** Илүү дутуу зүйл оруулахгүй, хамгийн бага шаардлагатай функцээр хязгаарлах.
- **R1.4** Зөвхөн **ерөнхий журнал**ын функцийг хэрэгжүүлэх.

### R2. Хуудас бүтэц
- **R2.1** Дараах хэсгүүдтэй байх:
  - Журналын жагсаалт
  - Тайлан
  - Дансны тохиргоо
- **R2.2** "**Журнал бичих**" нь tab биш, **товч (button)** байх.
- **R2.3** "Журнал бичих" товч дарахад **popup хэлбэрээр** гарч ирэх.

### R3. Журналын жагсаалт
- **R3.1** Багануудын дараалал: Огноо → Данс → Дебет → Кредит → **Гүйлгээний утга (хамгийн сүүлд)**.
- **R3.2** Журналын мэдээллийг **header (гарчиг)** ба **line (мөр)** гэж тусад нь ялгаж харуулах.
  - Header: огноо, гүйлгээний утга — нэг удаа.
  - Lines: данс, дебет, кредит, тайлбар — олон мөр.

### R4. Журнал бичих popup
- **R4.1** Header хэсэг: огноо, гүйлгээний утга.
- **R4.2** Мөр (line) хэсэг: тус бүрд данс, дебет, кредит сонгох/оруулах.
- **R4.3** "**Мөр нэмэх**" товчтой — олон мөр оруулах боломж.
- **R4.4** Мөр бүрд **тайлбар (description)** бичих талбартай.
- **R4.5** Дебет/Кредит хориглол:
  - **R4.5.1** Тухайн мөрөнд **dr (дебет)** талд утга бичсэн бол **cr (кредит)** талд оруулах боломжгүй.
  - **R4.5.2** Эсрэгээр ч адил — **cr** талд утга байвал **dr** хоригдоно.
  - **R4.5.3** Утгыг арилгасны дараа эсрэг тал дахин идэвхжих.
- **R4.6** Дебет/Кредит талбарт **зөвхөн тоон утга** оруулах боломжтой байх (`e`, `+`, `-`, текст блоклогдох).

### R5. Дансны тохиргоо
- **R5.1** Данс нэмэх процесс нь журнал бичихтэй ижилхэн **popup** хэлбэртэй байх.
- **R5.2** Хуудсан дотор шууд харуулсан форм байхгүй — зөвхөн "+ Данс нэмэх" товч popup нээх.

### R6. Документаци
- **R6.1** Хийгдсэн ажлуудыг README.md файлд баримтжуулах.
- **R6.2** Захиалагчийн хүсэлтүүдийг шаардлагын жагсаалт болгож оруулах.

## Хэсгүүд

Дээд цэс гурван хуудастай:

### 1. Журналын жагсаалт
- Хийгдсэн бичилтүүдийг **voucher блок** хэлбэрээр харуулна.
- Voucher блок бүрд:
  - Гарчиг: огноо ба гүйлгээний утга
  - Мөрүүд: Данс / Дебет / Кредит / Тайлбар
  - Voucher-ийн дэд дүн (Дебет / Кредит нийлбэр)
- Жагсаалтын төгсгөлд бүх voucher-ын нийт дүн ба тэнцсэн эсэх төлөв.
- Voucher тус бүрийг устгах боломжтой (× товч).
- Баруун дээд буланд **+ Журнал бичих** товч — popup нээнэ.

### 2. Тайлан
- Дөрвөн товч үзүүлэлт: нийт бичилт, нийт дебет, нийт кредит, зөрүү.
- Огнооны хязгаар (хамгийн эртний — хамгийн сүүлийн).
- Данс тус бүрийн дебет, кредит, үлдэгдэл.

### 3. Дансны тохиргоо
- Бүртгэлтэй дансны жагсаалт (Дугаар / Нэр).
- **+ Данс нэмэх** товч popup нээж шинэ данс нэмнэ.
- Анхдагч 4 данс суулгасан:
  - 1100 — Касс
  - 1200 — Харилцах данс
  - 5100 — Борлуулалтын орлого
  - 6100 — Үндсэн үйл ажиллагааны зардал
- Данс устгахдаа журналд ашиглагдсан бол баталгаажуулалт асуух.

## Журнал бичих popup

**Бүтэц:**

1. **Гарчиг (header):**
   - Огноо
   - Гүйлгээний утга

2. **Мөр (lines):** олон мөртэй хүснэгт
   - Данс (бүртгэлтэй данснаас сонгох)
   - Дебет
   - Кредит
   - Тайлбар (мөр тус бүрд)
   - × — мөр устгах

3. **Мөр нэмэх:** "+ Мөр нэмэх" товч.

**Хяналт:**
- Анхдагчаар 2 мөр бэлэн нээгдэнэ.
- Footer-т нийт дебет, нийт кредит, тэнцсэн эсэх статус.
- **Тэнцээгүй бол "Хадгалах" товч идэвхгүй.**
- Дор хаяж 2 мөр шаардана.

**Дебет/Кредит хориглол:**
- Нэг мөрөнд **дебет талд** утга оруулмагц **кредит** талбар саарал болж хоригдоно (эсрэгээр ч адил).
- Утгыг арилгахад эсрэг тал дахин нээгдэнэ.
- Зөвхөн тоон утга оруулна — `e`, `+`, `-` блоклогдоно.
- Тоон бус текстийг paste хийх боломжгүй.

**Хаах:**
- × товч, "Болих" товч, гадна талд дарах, эсвэл `Esc`.

## Дансны popup

- "+ Данс нэмэх" товчоор нээгдэнэ.
- Талбарууд: Дансны дугаар, Дансны нэр.
- `Enter` дарж шууд хадгална.
- Давхардсан дугаар бол анхааруулна.

## Өгөгдлийн бүтэц

`localStorage` түлхүүрүүд:

### `journal_vouchers_v1`
```json
[
  {
    "id": "string",
    "date": "YYYY-MM-DD",
    "desc": "string",
    "lines": [
      {
        "account": "1100",
        "debit": 0,
        "credit": 0,
        "desc": "string"
      }
    ]
  }
]
```

### `journal_accounts_v1`
```json
[
  { "number": "1100", "name": "Касс" }
]
```

## Технологи

- Цэвэр HTML / CSS / JavaScript (framework ашиглаагүй)
- Browser localStorage (өгөгдөл хадгалах)
- Гадны сангийн dependency байхгүй

## Ашиглах

1. `index.html` файлыг хөтчөөр нээх.
2. Эхэндээ "Дансны тохиргоо"-руу ороод хэрэглэх данснуудаа нэмэх.
3. "Журналын жагсаалт"-аас "+ Журнал бичих" товч дарж бичилт хийх.
4. "Тайлан" хэсгээс ерөнхий нийлбэр болон данс тус бүрийн үлдэгдлийг шалгах.

## Хязгаарлалт

- Олон хэрэглэгчийн дэмжлэг байхгүй (өгөгдөл зөвхөн уг хөтчид хадгалагдана).
- Нөөцлөлт / экспортын функц одоогоор байхгүй.
- Хөтчийн `localStorage`-ийг устгавал бүх өгөгдөл алдагдана.
