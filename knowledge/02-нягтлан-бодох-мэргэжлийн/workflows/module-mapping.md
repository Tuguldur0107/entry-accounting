## Tax-модуль hambaar

```
┌────────────┐     ┌─────────────────────────────────────┐
│   AR       │────→│ НӨАТ гаралтын (борлуулалт)          │
│ (Авлага)   │     │ WHT (гэрээлэгч орлого хүлээн авах)  │
└────────────┘     └─────────────────────────────────────┘

┌────────────┐     ┌─────────────────────────────────────┐
│   AP       │────→│ НӨАТ оролтын (худалдан авалт)        │
│ (Өглөг)    │     │ WHT суутгал (гэрээлэгчид төлөх)     │
└────────────┘     └─────────────────────────────────────┘

┌────────────┐     ┌─────────────────────────────────────┐
│   POS      │────→│ НӨАТ гаралтын (бэлэн борлуулалт)    │
│            │     │ Е-баримт                             │
└────────────┘     └─────────────────────────────────────┘

┌────────────┐     ┌─────────────────────────────────────┐
│  Payroll   │────→│ ХАОАТ суутгал (цалингаас)            │
│ (Цалин)    │     │ НДШ (ажилтан + ажил олгогч)          │
│            │     │ ЭМД (ажилтан + ажил олгогч)          │
└────────────┘     └─────────────────────────────────────┘

┌────────────┐     ┌─────────────────────────────────────┐
│   GL       │────→│ ААНОАТ (жилийн эцэст)               │
│            │     │ Хойшлогдсон татвар (IAS 12)          │
│            │     │ НӨАТ тооцоо (сарын)                  │
└────────────┘     └─────────────────────────────────────┘

┌────────────┐     ┌─────────────────────────────────────┐
│   FA       │────→│ Үл хөдлөх хөрөнгийн татвар           │
│            │     │ Татварын элэгдэл (ААНОАТ-д)          │
└────────────┘     └─────────────────────────────────────┘
```
