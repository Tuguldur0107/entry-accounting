# Бүрэн тооцооллын жишээ (end-to-end)

## Оролт

```
Ажилтан: Б.Болд
Албан тушаал: Нягтлан бодогч
Үндсэн цалин: 2,000,000₮/сар
Ажлын цаг: 168 (бүтэн сар)
Ажилласан цаг: 168
Илүү цаг: 5 цаг (ердийн × 1.5)
Урамшуулал: 150,000₮
Бусад суутгал: 50,000₮ (зээлийн төлбөр)
```

## Тооцоолол

### 1. Нийт олголт

```
Үндсэн цалин:  2,000,000 × (168/168) = 2,000,000₮
Цагийн хөлс:   2,000,000 / 168 = 11,905₮
Илүү цагийн:   11,905 × 1.5 × 5 = 89,288₮
Урамшуулал:     150,000₮
──────────────────────────────
Нийт олголт:    2,239,288₮
```

### 2. Ажилтны НДШ (дээд хязгаар: 7,920,000₮ → 2,239,288 < 7,920,000 тул бүтнээр)

```
Тэтгэвэр:      2,239,288 × 8.5%  = 190,339₮
Тэтгэмж:       2,239,288 × 0.8%  = 17,914₮
Ажилгүйдэл:   2,239,288 × 0.2%  = 4,479₮
ЭМД:           2,239,288 × 2.0%  = 44,786₮
──────────────────────────────
Нийт НДШ:      257,518₮
```

### 3. ХАОАТ

```
Татвар ногдох:   2,239,288 − 257,518 = 1,981,770₮
Шатлалт татвар:  1,981,770 × 10% = 198,177₮ (10 сая-д багтана)
Хөнгөлөлт:       1,981,770 ≤ 2,000,000 → 14,000₮
──────────────────────────────
ХАОАТ:           198,177 − 14,000 = 184,177₮
```

### 4. Гарт олгох цалин

```
Нийт суутгал:    257,518 + 184,177 + 50,000 = 491,695₮
──────────────────────────────
Цэвэр цалин:     2,239,288 − 491,695 = 1,747,593₮
```

### 5. Ажил олгогчийн НДШ (компанийн зардал)

```
Тэтгэвэр:      2,239,288 × 8.5% = 190,339₮
Тэтгэмж:       2,239,288 × 1.0% = 22,393₮
Ажилгүйдэл:   2,239,288 × 0.2% = 4,479₮
ЭМД:           2,239,288 × 2.0% = 44,786₮
ҮОМШӨ:         2,239,288 × 0.8% = 17,914₮
──────────────────────────────
Нийт АО НДШ:    279,911₮
```

### 6. Нийт хөдөлмөрийн зардал

```
2,239,288 + 279,911 = 2,519,199₮
```

## GL журнал (энэ ажилтны хувьд)

```
Dr 70000002 Цалингийн зардал      2,239,288₮
Dr 70000002 АО НДШ зардал           279,911₮
    Cr 31000004 НДШ өглөг           212,732₮  (257,518 − 44,786)
    Cr 31000004 ЭМД өглөг            44,786₮
    Cr 31000003 ХАОАТ өглөг         184,177₮
    Cr 31000002 Цалингийн өглөг   1,797,593₮  (net before loan deduction)
    Cr 12000005 Ажилтны зээлийн авлага 50,000₮  (бусад суутгалын мөр)
    Cr 31000004 АО НДШ өглөг        279,911₮
                              ──────────
    Нийт Dr: 2,519,199₮ = Нийт Cr: 2,519,199₮ ✓
```

> **Note:** Бусад суутгал (жишээ: зээлийн төлбөр, өмнөх цалингийн илүү төлөлт) нь тусдаа
> Cr мөр үүсгэх шаардлагатай. Одоогоор `generatePayrollJournalDraft.js` нь other_deductions-ийг
> journal line болгож чадахгүй — хэрэглэгч UI card дээр гараар нэмж оруулна.
> Guardrail `journal_unbalanced` алдаатай бол энэ мөр дутсан байж магадгүй.
