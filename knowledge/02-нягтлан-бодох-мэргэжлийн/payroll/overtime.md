# Илүү цагийн тооцоо (Overtime)

## Хөдөлмөрийн хуулийн дагуу

| Нөхцөл | Нэмэгдэл хувь |
|--------|----------------|
| Ердийн илүү цаг | **1.5x** (50% нэмэгдэл) |
| Амралтын өдөр | **1.5x** эсвэл нөхөн амралт |
| Баярын өдөр | **2.0x** (100% нэмэгдэл) |
| Шөнийн ээлж (22:00–06:00) | **+20%** нэмэгдэл |

## Тооцоолол

```
workHours = 168  (22 ажлын өдөр × 8 цаг = стандарт сарын цаг)
hourlyRate = baseSalary / workHours
overtimePay = hourlyRate × overtimeMultiplier × overtimeHours

Жишээ:
  baseSalary = 2,000,000₮
  hourlyRate = 2,000,000 / 168 = 11,905₮/цаг
  5 цаг илүү цаг × 1.5 = 11,905 × 1.5 × 5 = 89,288₮
```

## Ажлын цагийн стандарт

| Үзүүлэлт | Утга |
|-----------|------|
| 1 өдрийн ажлын цаг | 8 цаг |
| 7 хоногийн ажлын цаг | 40 цаг |
| Сарын ажлын өдөр (дундаж) | 22 өдөр |
| Сарын ажлын цаг | 168–176 цаг |
| Жилийн ажлын цаг | ~2,080 цаг |

## Онцгой тохиолдол

- **Хүнд нөхцөлд ажиллагчид:** 36 цаг/долоо хоног (НХ 101)
- **Шөнийн ажил:** 22:00–06:00 хооронд 20% нэмэгдэлтэй
- **Баярын өдөр:** 2.0x, хэрэв урт баяр (3+ өдөр) бол нөхөн амралт
- **Зөвшөөрөл:** илүү цагаар ажиллуулахын тулд ажил олгогч ажилтны зөвшөөрлөөр, сард 40 цагаас ихгүй
