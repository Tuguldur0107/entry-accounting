# Payroll тайлагнал

## Ажилтны цалингийн хуудас (Payslip)

- Ажилтны мэдээлэл, албан тушаал, Төрсөн өдөр, РД
- Нийт олголт (gross), суутгалын задаргаа, гарт олгох (net)
- НДШ, ХАОАТ задаргаа (мөр тус бүр)
- Илүү цаг, урамшуулалын задаргаа
- Ажилласан цаг, отсон/чөлөө авсан цаг

## Нэгтгэл тайлан

- **Сарын нэгтгэл:** нийт gross, НДШ (employee + employer), ЭМД, ХАОАТ, net
- **Хэлтсийн нэгтгэл:** хэлтэс тус бүрээр gross/net/cost
- **Жилийн нэгтгэл:** ажилтан тус бүрийн 12 сарын задаргаа — ТТ-11 маягт-д хэрэгтэй

## Дашбоард (KPI)

- Нийт ажилтны тоо (идэвхтэй)
- Тухайн сарын нийт gross / net
- YTD (жилийн эхнээс) нийт дүн
- Хүлээгдэж буй цалин бодолтын тоо (draft/calculated төлөвтэй)
- Хэлтсийн задаргаа (pie chart)
- Headcount trend (12 сар)

## Төлбөрийн жагсаалт (Disbursement)

- Банкны шилжүүлгийн файл (Хан Банк, Голомт, ХХБ гэх мэт format)
- Ажилтан бүрийн банкны данс, net дүн
- Batch-аар upload хийх боломжтой

## Тайлагналын хуваарь (хүргэх)

| Тайлан | Давтамж | Хугацаа |
|--------|---------|---------|
| НДШ шимтгэлийн тайлан | Сар бүр | Дараа сарын 5 |
| ХАОАТ суутгалын тайлан | Сар бүр | Дараа сарын 10 |
| НДШ жилийн тайлан | Жил бүр | 2-р сарын 15 |
| ХАОАТ жилийн тайлан (ТТ-11) | Жил бүр | 2-р сарын 15 |
| Ажил олгогчийн тодорхойлолт | Хүсэлтээр | — |

## Ажлын урсгал (workflow)

```
1. Цалин бодолт үүсгэх (Create Run)
   → Бүх идэвхтэй ажилтнууд нэмэгдэнэ
   → Статус: draft

2. Мөр засварлах (Edit Lines)
   → Ажлын цаг, илүү цаг, урамшуулал, суутгал оруулах
   → Статус: draft хэвээр

3. Тооцоолох (Calculate)
   → POST /api/payroll-runs/:id/calculate
   → НДШ, ХАОАТ, цэвэр цалин автоматаар бодогдоно
   → Статус: calculated

4. Шалгах ба батлах
   → Тооцооллыг шалгаад зөв бол posting хийнэ

5. GL Posting
   → POST /api/payroll-runs/:id/post
   → 7 мөрийн журнал автомат үүснэ
   → Статус: posted (цаашид засах боломжгүй)
```

### Статусын диаграм

```
draft → calculated → posted
  ↑         ↓
  └─── (дахин засвал draft руу буцна)
```
