# Payroll GL журнал — 7 мөрийн бичилт

Цалин бодолтыг GL-д posting хийхэд **7 мөрийн журнал** бичигдэнэ.

## Дебит талууд (2 мөр)

```
Мөр 1: Dr 70000002 Цалингийн зардал             — totalEarnings
Мөр 6: Dr 70000002 Ажил олгогчийн НДШ зардал    — totalEmployerSI
```

## Кредит талууд (5 мөр)

```
Мөр 2: Cr 31000004 НДШ өглөг                    — totalSI − totalHealthIns
Мөр 3: Cr 31000004 ЭМД өглөг                    — totalHealthIns
Мөр 4: Cr 31000003 ХАОАТ өглөг                  — totalPIT
Мөр 5: Cr 31000002 Цалингийн өглөг              — totalNet (гарт олгох)
Мөр 7: Cr 31000004 Ажил олгогчийн НДШ өглөг     — totalEmployerSI
```

## Баланс шалгалт

```
Нийт Дебит  = totalEarnings + totalEmployerSI
Нийт Кредит = (SI − HI) + HI + PIT + netSalary + totalEmployerSI
            = totalEarnings + totalEmployerSI  ✓
```

Debit = Credit заавал. Guardrail: [guardrails/journal-balance.md](../../guardrails/journal-balance.md) харна уу.

## Төлбөр хийх үед (тусдаа журнал)

```
Цалин олголт:         Dr 31000002 Цалингийн өглөг   / Cr 11000001 Банк
ХАОАТ төлөлт:         Dr 31000003 ХАОАТ өглөг       / Cr 11000001 Банк
НДШ төлөлт:           Dr 31000004 НДШ өглөг         / Cr 11000001 Банк
ЭМД төлөлт:           Dr 31000004 ЭМД өглөг         / Cr 11000001 Банк
Ажил олгогчийн НДШ:   Dr 31000004 АО НДШ өглөг      / Cr 11000001 Банк
```
