# ААНОАТ — Аж ахуйн нэгжийн орлогын албан татвар (CIT)

**Модуль:** GL

## Үндсэн мэдээлэл

- **Хууль:** Аж ахуйн нэгжийн орлогын албан татварын тухай хууль
- **Тайлант хугацаа:** Хуанлийн жил (01/01 – 12/31)
- **Төлөгч:** Монгол Улсад бүртгэлтэй бүх аж ахуйн нэгж

## Татварын хувь хэмжээ (2025)

| Татвар ногдох орлого | Хувь |
|----------------------|------|
| 0 – 6 тэрбум ₮ | **10%** |
| 6 тэрбум ₮-аас дээш | **25%** |

> *Уул уурхайн салбар: Нэмэлт 10%–30% (ашигт малтмалын нөөц ашигласны татвар)*

## Татвар ногдох орлогын тооцоолол

```
Нийт орлого (Revenue)
− Борлуулалтын өртөг (COGS)
− Үйл ажиллагааны зардал (Operating expenses)
+ Бусад орлого (Other income)
− Татвараас хасагдах зардлууд (Deductible expenses)
+ Татвараас хасагдахгүй зардлууд (Non-deductible — буцааж нэмнэ)
══════════════════════════
= Татвар ногдох орлого (Taxable income)
```

## Татвараас хасагдах зардал (Deductible)

- Бизнесийн үйл ажиллагаатай шууд холбоотой зардал
- Ажилтны цалин, НДШ (ажил олгогчийн хувь)
- Элэгдэл (татварын зориулалтаар тооцсон)
- Зээлийн хүү (бизнесийн зориулалтын)
- Түрээсийн зардал
- Даатгалын шимтгэл
- **Сурталчилгааны зардал** (орлогын **2%** хүртэл)
- **Хандивын зардал** (орлогын **1%** хүртэл)
- Найдваргүй авлагын зардал (нотлох баримттай)

## Татвараас хасагдахгүй зардал (Non-deductible)

- Торгууль, алданги
- ААНОАТ өөрөө
- Хувийн зориулалтын зардал
- Баримтгүй зардал
- Сурталчилгааны 2%-иас хэтэрсэн хэсэг
- Хандивын 1%-иас хэтэрсэн хэсэг
- Зориулалтын бус элэгдэл (татварын хуулиар зөвшөөрөгдөөгүй хурдасгасан элэгдэл)

## Татварын элэгдэл vs Нягтлан бодохын элэгдэл

| Хөрөнгийн ангилал | Татварын элэгдлийн хувь | Нягтлан бодохын (IAS 16) |
|--------------------|--------------------------|---------------------------|
| Барилга | 5% | 2%–5% |
| Тоног төхөөрөмж | 10% | 7%–20% |
| Тээврийн хэрэгсэл | 10% | 10%–20% |
| Компьютер | 20% | 20%–33% |
| Биет бус хөрөнгө | 10% | Хувьсах |

**Зөрүү → IAS 12 хойшлогдсон татвар (Deferred tax)**

```
Татварын элэгдэл > Нягтлан бодохын → Хойшлогдсон татварын өр (DTL)
Татварын элэгдэл < Нягтлан бодохын → Хойшлогдсон татварын хөрөнгө (DTA)
```

## Урьдчилгаа ААНОАТ (Quarterly estimates)

```
Улирлын урьдчилгаа = Тухайн улирлын ашиг × татварын хувь
Жилийн эцсийн тооцоо = Жилийн ААНОАТ − Төлсөн урьдчилгааны нийлбэр

Жилийн > урьдчилгаа → Нэмж төлнө
Жилийн < урьдчилгаа → Буцаан авна / дараа жилд шилжүүлнэ
```

## GL журнал

```
Улирлын ААНОАТ урьдчилгаа:
  Dr 12000002 Урьдчилж төлсөн татвар   / Cr 11000001 Банк

Жилийн эцсийн ААНОАТ тооцоо:
  Dr 87000002 ААНОАТ зардал             / Cr 31000003 ААНОАТ өглөг
  Dr 31000003 ААНОАТ өглөг              / Cr 12000002 Урьдчилж төлсөн татвар (хаах)
  Dr 31000003 ААНОАТ өглөг              / Cr 11000001 Банк (үлдэгдэл төлөх)

Хойшлогдсон татварын өр (DTL) үүсэх:
  Dr 87000002 ААНОАТ зардал             / Cr 33000003 Хойшлогдсон татварын өр

Хойшлогдсон татварын хөрөнгө (DTA) үүсэх:
  Dr 26000001 Хойшлогдсон татварын хөрөнгө / Cr 87000002 ААНОАТ зардал (буцаалт)
```

## ААНОАТ тайлангийн бүтэц

```
1. Нийт орлого
2. − Хасагдах зардал
3. = Татвар ногдох орлого
4. × Татварын хувь (10% / 25%)
5. = Нийт ААНОАТ
6. − Урьдчилж төлсөн
7. = Төлөх / Буцаан авах дүн
```

## Тайлагналын хугацаа

- Улирлын урьдчилгаа → **дараа улирлын 25-нд** (4/25, 7/25, 10/25, 1/25)
- Жилийн тайлан → **2-р сарын 10**
