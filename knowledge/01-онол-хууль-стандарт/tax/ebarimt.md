# Е-баримт (eBarimt)

**Модуль:** POS, AR

## Ерөнхий мэдээлэл

- Монгол Улсын НӨАТ-ын цахим баримтын систем
- Бүх НӨАТ бүртгэлтэй ААН заавал ашиглана
- **eBarimt.mn** — татварын ерөнхий газрын систем

## Баримтын төрөл

| Төрөл | Тайлбар |
|-------|---------|
| Иргэнд олгох (B2C) | Иргэний РД дугаар эсвэл lottery |
| Байгууллагад олгох (B2B) | ААН-ийн РД дугаар, оролтын НӨАТ авна |

## API интеграц (цаашид хөгжүүлэх)

```
POST /api/ebarimt/send     — Баримт илгээх
GET  /api/ebarimt/check    — Баримтын төлөв шалгах
POST /api/ebarimt/cancel   — Баримт цуцлах
GET  /api/ebarimt/report   — Сарын нэгтгэл
```

## Хэрэгжүүлэлтийн заавар

- POS борлуулалт → автомат е-баримт илгээх
- AR нэхэмжлэл → нэхэмжлэл дээр е-баримтын дугаар хадгалах
- `pos_sales`, `ar_invoices` дээр `ebarimt_id`, `ebarimt_lottery`, `ebarimt_status` талбар
- Алдаатай илгээлтийг retry queue-т оруулах

## Зөрчил ба торгууль

- Е-баримт олгоогүй → Борлуулалтын дүнгийн **20%** торгууль
- Нэхэмжлэл + e-баримт зөрүүтэй → мөн 20% торгууль
