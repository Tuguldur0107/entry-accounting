# Татварын торгууль ба хариуцлага

## Хугацаа хоцорсны алданги

| Зөрчил | Алданги/Торгууль |
|--------|------------------|
| Татвар хугацаандаа төлөөгүй | Хоног бүр **0.1%** (жилд ~36%) |
| Тайлан хугацаандаа өгөөгүй | Хоног бүр **0.1%** |
| Дутуу мэдүүлсэн | Зөрүүний **30%** |
| Худал мэдүүлсэн | Зөрүүний **30%–50%** |
| НӨАТ баримт зөрчил | Нэхэмжлэлийн дүнгийн **20%** |
| Е-баримт олгоогүй | Борлуулалтын дүнгийн **20%** |
| НДШ шимтгэл төлөөгүй | Хоног бүр **0.1%** |

## Тооцоолол

```javascript
function calculatePenalty(amount, daysLate) {
  // 0.1% per day
  return Math.round(amount * 0.001 * daysLate)
}

// Жишээ: 5,000,000₮ татвар, 30 хоног хоцорсон
// Алданги = 5,000,000 × 0.001 × 30 = 150,000₮
```

## GL журнал

```
Торгууль/алданги:
  Dr 87000002 Торгуулийн зардал  / Cr 31000003 Татварын өглөг
```

> **Важно:** Торгуулийн зардал **ААНОАТ-аас хасагдахгүй** (non-deductible). DTA/DTL-д permanent difference болно.

## Хэрэгжүүлэлт

- `tax_penalties` хүснэгт: tax_type, base_amount, days_late, penalty_rate, penalty_amount, period_id
- Автомат тооцоолол сар бүр: хэрэв тайлан хугацаандаа гараагүй бол алдангийг auto-accrue
- Хүний зөвшөөрлөөр manual adjustment
