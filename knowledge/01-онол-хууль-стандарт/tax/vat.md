# НӨАТ — Нэмэгдсэн өртгийн албан татвар (VAT)

**Модуль:** AR, AP, POS, GL

## Үндсэн мэдээлэл

- **Хувь:** **10%**
- **Бүртгэлийн босго:** 400 сая ₮/жил (2026-аас) — өмнө 50 сая
- **Хууль:** Нэмэгдсэн өртгийн албан татварын тухай хууль (2015, шинэчилсэн 2025)

## Бүртгэх / Бүртгэхгүй

**НӨАТ-д заавал бүртгүүлэх:**
- Жилийн борлуулалт ≥ **400 сая ₮** (2026-аас)
- Сайн дурын бүртгэл: босгоноос доогуур ч гэсэн бүртгүүлж болно

**НӨАТ ногдуулахгүй (чөлөөлөгдсөн):**
- Эмнэлгийн үйлчилгээ
- Боловсролын үйлчилгээ
- Санхүүгийн үйлчилгээ (банкны хүү, даатгал)
- Олон нийтийн тээвэр
- Орон сууц түрээслэх (иргэнд)

**НӨАТ 0% (zero-rated):**
- Экспортын бараа, үйлчилгээ
- Олон улсын тээвэр

## Тооцооллын горим

### 1. Exclusive (НӨАТ-гүй үнэ дээр нэмэх)

```
subtotal = 1,000,000₮
vat = subtotal × 10% = 100,000₮
total = 1,100,000₮
```

### 2. Inclusive (НӨАТ-тай үнэнд багтсан)

```
total = 1,100,000₮
subtotal = total / 1.10 = 1,000,000₮
vat = total - subtotal = 100,000₮
```

## Сарын НӨАТ тооцоо

```
Гаралтын НӨАТ (output) = Борлуулалтын НӨАТ (AR + POS)
Оролтын НӨАТ (input)   = Худалдан авалтын НӨАТ (AP)

Төлөх НӨАТ = Гаралтын НӨАТ − Оролтын НӨАТ

Хэрэв Гаралтын < Оролтын:
  → Илүү төлсөн НӨАТ (буцаан авах эсвэл дараа сард шилжүүлэх)
```

## Оролтын НӨАТ хасах боломжгүй тохиолдол

- НӨАТ-аас чөлөөлөгдсөн үйл ажиллагаатай холбоотой худалдан авалт
- Зөв баримтгүй (е-баримтгүй)
- Хувийн хэрэглээний зардал
- Зочид буудал, зоогийн газрын зардал (**50% хязгаарлалт**)

## Тайлагналын хугацаа

- Сар бүр → **дараа сарын 10-нд** НӨАТ тайлан + төлбөр
- Жилд нэг удаа → **1-р сарын 15-нд** жилийн нэгтгэл
