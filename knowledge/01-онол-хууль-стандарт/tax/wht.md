# Суутган татвар (Withholding Tax — WHT)

**Модуль:** AP

## Хэзээ суутгана

Аж ахуйн нэгж дараах төлбөрийг хийхдээ суутган татвар суутгана:

| Төлбөрийн төрөл | WHT хувь | Тайлбар |
|-------------------|----------|---------|
| Бие даасан гэрээлэгч (хувь хүн) | **10%** | ХАОАТ суутгал |
| Ногдол ашиг (иргэнд) | **10%** |  |
| Ногдол ашиг (ААН-д) | **10%** | Эцсийн татвар |
| Роялти | **10%** |  |
| Хүү (иргэнд) | **10%** | Банкнаас суутгана |
| Үл хөдлөх хөрөнгийн түрээс (иргэнээс) | **10%** |  |
| Гадаадын ААН-д төлөх (Монголд эх үүсвэртэй) | **20%** | Гэрээгээр бууруулж болно |

## Гадаад төлбөрийн WHT (20%)

- Монголд эх үүсвэртэй орлого — гадаадын ААН-д төлөхөд
- Давхар татварын гэрээ (DTA) байвал бууруулж болно
- Монгол 40+ улстай DTA-тай (ОХУ, БНХАУ, Солонгос, Япон, Канад г.м)

## AP модулийн хэрэгжүүлэлт

- `ap_invoices` дээр `wht_rate`, `wht_amount` талбар нэмэх
- Нийлүүлэгч (supplier) дээр `is_individual` эсвэл `supplier_type` ялгах
- Хувь хүн нийлүүлэгч → WHT автомат тооцоолол
- Гадаад нийлүүлэгч → 20% WHT (DTA бууралт тохируулах боломж)

## Checklist

- [ ] Нийлүүлэгчийн төрөл (individual | entity | non-resident) бүрт effective rate байгаа эсэх
- [ ] DTA бууралт байгаа эсэх шалгасан (гадаад ААН)
- [ ] WHT суутгалын тайлан сар бүр гаргагдаж байгаа эсэх
