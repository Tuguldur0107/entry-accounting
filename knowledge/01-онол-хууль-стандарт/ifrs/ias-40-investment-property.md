# IAS 40 — Хөрөнгө оруулалтын зориулалттай үл хөдлөх хөрөнгө (Investment Property)

**Модуль:** FA

## Тодорхойлолт

- Түрээсийн орлого олох **эсвэл** үнэ цэнийн өсөлт хүлээх зориулалтаар эзэмшиж буй газар, барилга
- Өөрийн үйл ажиллагаанд ашигладаг биш (тэр нь IAS 16)

## Хоёр загвар

### 1. Өртгийн загвар (Cost model)

- IAS 16-тай ижил: Өртөг − Хуримтлагдсан элэгдэл − Бууралт
- Бодит үнэ цэнийг тодруулгад харуулна

### 2. Бодит үнэ цэнийн загвар (Fair value model)

- Тайлант хугацааны эцэст бодит үнэ цэнээр хэмжинэ
- Өөрчлөлтийг **ашиг алдагдалд** бичнэ (OCI биш!)
- Элэгдүүлэхгүй

## GL журнал

```
Бодит үнэ цэнийн өсөлт:
  Dr 27000001 Хөрөнгө оруулалтын үл хөдлөх  / Cr 51000002 Бодит үнэ цэнийн ашиг (P&L)

Бодит үнэ цэнийн бууралт:
  Dr 87000002 Бодит үнэ цэнийн алдагдал     / Cr 27000001 Хөрөнгө оруулалтын үл хөдлөх

Түрээсийн орлого:
  Dr 12000001 Авлага / 11000001 Банк          / Cr 51000002 Түрээсийн орлого
```

## Хэрэгжүүлэлт

- `fa_assets` хүснэгтэд `asset_class`: `ppe` (IAS 16), `investment_property` (IAS 40), `intangible` (IAS 38)
- Бодит үнэ цэнийн загвар → элэгдэл бодохгүй, зөвхөн revaluation
