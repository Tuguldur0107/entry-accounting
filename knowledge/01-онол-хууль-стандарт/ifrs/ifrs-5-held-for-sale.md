# IFRS 5 — Борлуулахаар ангилсан эргэлтийн бус хөрөнгө (Non-current Assets Held for Sale)

**Модуль:** FA

## Ангилах шалгуур

- Удирдлага борлуулах шийдвэр гаргасан
- Идэвхтэй борлуулалтын хөтөлбөр эхлүүлсэн
- 12 сарын дотор борлуулагдах магадлалтай
- Зохистой үнээр идэвхтэй зарж байгаа

## Хэмжилт

- **Дансны үнэ** ба **бодит үнэ цэнэ − борлуулах зардал**-ын аль **бага**
- Элэгдүүлэхгүй (held for sale ангилалд шилжсэнээс хойш)

## GL журнал

```
Held for sale-д шилжүүлэх:
  Dr 19000002 Борлуулахаар ангилсан хөрөнгө  / Cr 20000001 Үндсэн хөрөнгө (дансны үнэ)
  Dr 20000002 Хуримтлагдсан элэгдэл          / Cr 20000001 Үндсэн хөрөнгө (өртөг)

Бууралт (хэрэв бодит үнэ < дансны үнэ):
  Dr 87000002 Бууралтын алдагдал              / Cr 19000002 Борлуулахаар ангилсан хөрөнгө

Борлуулсан:
  Dr 11000001 Банк / 12000001 Авлага          / Cr 19000002 Борлуулахаар ангилсан хөрөнгө
  Dr/Cr 87000004 Борлуулалтын ашиг/алдагдал
```

## Хэрэгжүүлэлт

- `fa_assets` дээр `status`: `active`, `disposed`, `held_for_sale`
- Held for sale → элэгдэл зогсоох
- Баланс дээр тусдаа мөрөнд харуулна (эргэлтийн хөрөнгийн дотор)
