# IFRS 3 — Бизнес нэгтгэл (Business Combinations)

**Модуль:** AGIS, GL

## Худалдан авалтын арга (Acquisition method)

1. **Худалдан авагчийг тодорхойлох**
2. **Худалдан авалтын өдрийг тогтоох**
3. **Хүлээн зөвшөөрөх ба хэмжих:**
   - Тодорхойлогдох хөрөнгө, өр төлбөрийг бодит үнэ цэнээр
4. **Гудвилл эсвэл хямд үнээр худалдан авалтын ашиг тооцоолох**

## Гудвилл

```
Гудвилл = Худалдан авалтын дүн − Цэвэр хөрөнгийн бодит үнэ цэнэ
```

- Гудвилл > 0 → Хөрөнгө (элэгдүүлэхгүй, жил бүр impairment шалгана — IAS 36)
- Гудвилл < 0 → Bargain purchase gain (шууд P&L-д)

## GL журнал

```
Бизнес нэгтгэл:
  Dr XXXXXXXX Тодорхойлогдох хөрөнгүүд (бодит үнэ цэнээр)
  Dr 21000001 Гудвилл (зөрүү бол)
  Cr XXXXXXXX Тодорхойлогдох өр төлбөрүүд (бодит үнэ цэнээр)
  Cr 11000001 Банк / 41000001 Хувьцаа (төлсөн дүн)
```

## Хэрэгжүүлэлт

- `companies` хүснэгт: acquisition_date, acquisition_cost, goodwill_balance
- Fair value gap allocation: хөрөнгө/өр тус бүрт FV adjustment бичилт
- Гудвиллын impairment test жил бүр
