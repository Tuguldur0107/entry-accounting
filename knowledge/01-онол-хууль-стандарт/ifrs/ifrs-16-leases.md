# IFRS 16 — Түрээс (Leases)

**Модуль:** FA, GL

## Түрээслэгчийн бүртгэл (Lessee)

- **Ашиглах эрхийн хөрөнгө (Right-of-Use Asset):** Түрээсийн хугацааны өнөөгийн үнэ цэнэ
- **Түрээсийн өр төлбөр (Lease Liability):** Түрээсийн төлбөрийн өнөөгийн үнэ цэнэ

## Анхны хэмжилт

```
ROU хөрөнгийн өртөг = Түрээсийн өр + Урьдчилсан төлбөр + Шууд зардал − Урамшуулал
Түрээсийн өр = PV(Түрээсийн төлбөрүүд, хүүгийн хувь)
```

## Дараагийн хэмжилт

- ROU хөрөнгө → Элэгдүүлнэ (IAS 16-тай адил)
- Түрээсийн өр → Хүүг зардалд, үндсэн дүнг төлнө

## GL журнал

```
Анхны бүртгэл:
  Dr 20000001 ROU хөрөнгө            / Cr 33000001 Түрээсийн өр

Сарын элэгдэл:
  Dr 70000002 Элэгдлийн зардал        / Cr 20000002 ROU хуримтлагдсан элэгдэл

Сарын түрээсийн төлбөр:
  Dr 33000001 Түрээсийн өр (үндсэн)   / Cr 11000001 Банк
  Dr 87000001 Хүүгийн зардал           / Cr 11000001 Банк
```

## Онцгой тохиолдол (хүлээн зөвшөөрөхгүй)

- **Богино хугацааны түрээс (≤12 сар)** → Шууд зардалд
- **Бага үнэ цэнийн хөрөнгийн түрээс (≤$5,000 / ~17 сая ₮)** → Шууд зардалд

## Хэрэгжүүлэлт

- `lease_contracts` хүснэгт: term, payment schedule, discount rate, commencement date
- Сар бүрийн PV recalculation background job
- Modification (term change, rate change) → remeasurement rule
