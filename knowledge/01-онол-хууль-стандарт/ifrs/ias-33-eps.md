# IAS 33 — Нэгж хувьцаанд ногдох ашиг (Earnings Per Share)

**Модуль:** Reports

## Хоёр үзүүлэлт

### 1. Суурь EPS (Basic EPS)

```
Basic EPS = (Цэвэр ашиг − Давуу эрхтэй хувьцааны ногдол ашиг) / Жигнэсэн дундаж энгийн хувьцааны тоо
```

### 2. Сулруулсан EPS (Diluted EPS)

```
Diluted EPS = (Тохируулсан цэвэр ашиг) / (Жигнэсэн дундаж + Сулруулах боломжтой хувьцааны тоо)
```

- Сулруулах хэрэглүүр: хувьцааны опцион, конвертлох бонд, варрант

## Хэрэгжүүлэлт

- Орлогын тайлан дээр EPS харуулах (хувьцаат компанид)
- Жигнэсэн дундаж хувьцааны тоог хугацаагаар тооцоолох
- Монголын ихэнх SME-д хэрэглэхгүй (хувьцаат компани биш бол)
