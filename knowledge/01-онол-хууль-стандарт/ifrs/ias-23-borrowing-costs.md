# IAS 23 — Зээлийн зардал (Borrowing Costs)

**Модуль:** FA, GL

## Гол зарчим

- **Шууд холбоотой зээлийн зардлыг капиталчилна** — qualifying asset-д
- **Qualifying asset** = Ашиглалтад оруулахад мэдэгдэхүйц хугацаа шаардагдах хөрөнгө

## Qualifying assets жишээ

- Барилга байгууламж (барилгын үе шатанд)
- Үйлдвэрийн тоног төхөөрөмж (суурилуулалтын хугацаанд)
- Биологийн хөрөнгө (ургалт/өсөлтийн хугацаанд)

## Капиталчлах хугацаа

- **Эхлэх:** Зардал гарч, зээлийн зардал хуримтлагдаж, хөрөнгийг бэлтгэж эхлэх үед
- **Зогсоох:** Идэвхтэй хөгжүүлэлт зогссон үед (түр)
- **Дуусгах:** Хөрөнгө зориулалтын дагуу ашиглалтад орсон үед

## GL журнал

```
Зээлийн хүү (капиталчлах):
  Dr 20000001 Дуусаагүй барилга/Тоног төхөөрөмж  / Cr 32000002 Хүүгийн өглөг

Зээлийн хүү (зардалд бичих — qualifying биш):
  Dr 87000001 Санхүүгийн зардал (хүүгийн зардал)  / Cr 32000002 Хүүгийн өглөг
```
