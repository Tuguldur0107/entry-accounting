# IAS 28 — Хамтарсан аж ахуйн нэгж ба нөлөө бүхий хөрөнгө оруулалт (Investments in Associates and Joint Ventures)

**Модуль:** AGIS, GL

## Мэдэгдэхүйц нөлөө (Significant Influence)

- Ихэвчлэн **20%-50%** саналын эрх эзэмших
- Тусгай аргаар (equity method) бүртгэнэ

## Equity method (Тусгай арга)

```
Анхны хүлээн зөвшөөрөлт: Өртгөөр
Дараагийн хэмжилт:
  Дансны үнэ = Өртөг + Хувь тэнцүү ашиг − Хувь тэнцүү алдагдал − Хүлээн авсан ногдол ашиг
```

## GL журнал

```
Хөрөнгө оруулалт хийх:
  Dr 24000001 Урт хугацаат хөрөнгө оруулалт  / Cr 11000001 Банк

Хувь тэнцүү ашиг:
  Dr 24000001 Хөрөнгө оруулалт    / Cr 51000002 Хөрөнгө оруулалтын орлого

Ногдол ашиг хүлээн авах:
  Dr 11000001 Банк                 / Cr 24000001 Хөрөнгө оруулалт (дансны үнэ бууруулна)
```
