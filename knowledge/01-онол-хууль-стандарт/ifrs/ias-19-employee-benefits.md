# IAS 19 — Ажилтны тэтгэмж (Employee Benefits)

**Модуль:** Payroll

## Монгол хуулийн дагуу

- **НДШ (Нийгмийн даатгал):**
  - Ажил олгогч: **12.5%** (2026: 14.5% хүртэл өснө)
  - Ажилтан: **11.5%**
  - НДШ-ийн дээд хязгаар: Шимтгэл ногдуулах орлогын дээд хэмжээ (**10× доод цалин**)

- **ЭМД (Эрүүл мэндийн даатгал):**
  - Ажил олгогч: **1%**
  - Ажилтан: **1%**

- **ХАОАТ:** Цалингаас суутгах (IAS 12 хэсэг харах)

## Цалин бодолтын дараалал (IAS 19 + Монгол хууль)

```
1. Нийт цалин (Gross salary)
2. − ХАОАТ (PIT)
3. − НДШ ажилтны хувь (11.5%)
4. − ЭМД ажилтны хувь (1%)
5. = Гарт олгох цалин (Net salary)

Ажил олгогчийн зардал:
6. + НДШ ажил олгогчийн хувь (12.5%)
7. + ЭМД ажил олгогчийн хувь (1%)
8. = Нийт хөдөлмөрийн зардал
```

## GL журнал

```
Цалин бодолт (сар эцэст):
  Dr 70000002 Цалингийн зардал (gross + employer НДШ + employer ЭМД)
  Cr 31000002 Цалингийн өглөг (net)
  Cr 31000003 ХАОАТ өглөг
  Cr 31000004 НДШ өглөг (ажилтан + ажил олгогч)
  Cr 31000004 ЭМД өглөг (ажилтан + ажил олгогч)

Цалин олголт:
  Dr 31000002 Цалингийн өглөг  / Cr 11000001 Банк

Татвар/шимтгэл төлөлт:
  Dr 31000003 ХАОАТ өглөг      / Cr 11000001 Банк
  Dr 31000004 НДШ өглөг        / Cr 11000001 Банк
```

## Хэрэгжүүлэлтийн нөхцөл

- Rate version `payroll_rate_versions` хүснэгтээс effective date-аар lookup
- НДШ cap = 10 × minimum wage × гэрээний хувь
- Employer rate жил бүр шинэчлэгдэх боломжтой (2026: 14.5% хүртэл)
- Долгой хугацааны тэтгэмжид (pensions, termination benefits) present value хэрэглэх
