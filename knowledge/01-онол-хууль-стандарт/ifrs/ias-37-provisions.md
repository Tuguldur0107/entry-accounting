# IAS 37 — Нөөц, болзошгүй өр, болзошгүй хөрөнгө (Provisions, Contingent Liabilities)

**Модуль:** GL, AP

## Нөөц бүртгэх 3 шалгуур (бүгд хангагдах ёстой)

1. Өнгөрсөн үйл явдлаас үүссэн одоогийн үүрэг
2. Үүргийг биелүүлэхэд эдийн засгийн ашиг тус шаардагдах магадлал > 50%
3. Дүнг найдвартай тооцоолох боломжтой

## Түгээмэл нөөцүүд

- Баталгаат засварын нөөц (warranty provision)
- Шүүхийн нөөц (legal provision)
- Буулгалтын нөөц (decommissioning — IAS 16-тэй холбоотой)
- Рестокрacturing нөөц
- Орчны бохирдлын нөөц

## Ангилал

| Магадлал | Нягтлан бодох бүртгэл |
|----------|-----------------------|
| > 50% + найдвартай тооцоолол | **Provision** (бүртгэнэ) |
| > 50% гэхдээ тооцоолох боломжгүй | Contingent liability (тодруулга) |
| < 50% гэхдээ > Remote | Contingent liability (тодруулга) |
| Remote | Мэдээлэхгүй |

## GL журнал

```
Warranty provision:
  Dr 70000002 Баталгаат засварын зардал  / Cr 32000003 Баталгаат засварын нөөц

Нөөц хэрэглэгдсэн:
  Dr 32000003 Баталгаат засварын нөөц    / Cr 11000001 Банк / 31000001 Өглөг

Нөөц цуцлагдсан:
  Dr 32000003 Нөөц                       / Cr 51000002 Бусад орлого
```

## Хэрэгжүүлэлт

- `provisions` хүснэгт: type, amount, probability, expected_outflow_date
- Тайлант хугацаа бүрийн эцэст нөөцийг дахин үнэлэх (remeasurement)
- Present value дээр тооцоолох — хугацаа ≥ 1 жил
