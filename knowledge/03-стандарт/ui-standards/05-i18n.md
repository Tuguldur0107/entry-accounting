## 3. API — `getT` ба `useLanguage`

### 3.1 `getT(lang)` (index.ts)

```ts
export function getT(lang: Lang) {
  return (key: TranslationKey | string): string =>
    translations[lang]?.[key as TranslationKey]
      ?? translations['en']?.[key as TranslationKey]
      ?? key   // fallback chain: lang → en → raw key
}
```

**Fallback хэлбэр:**
1. Сонгосон хэл (mn/zh/ru/en).
2. English (хэрэв тухайн key уг хэлд алга).
3. Raw key (хэрэв English-д ч алга — debug-д тус болно).

### 3.2 `formatTranslation(template, values)`

Variable interpolation `{var}` syntax:

```ts
formatTranslation('{name} нь {amount} ₮ нэхэмжилсэн', { name: 'Бат', amount: '1,000' })
// → "Бат нь 1,000 ₮ нэхэмжилсэн"
```

> Plural / gender форм одоогоор дэмжихгүй (V1.07-д ICU MessageFormat нэмэх төлөвлөгөөтэй).

### 3.3 React-аар хэрэглэх — `useLanguage()`

`LanguageProvider` бүх app-ыг wrap хийдэг. `useLanguage()` hook:

```ts
const { lang, setLang, t } = useLanguage()

return <Text>{t('btn_save')}</Text>
```

| Field | Type | Тайлбар |
|-------|------|---------|
| `lang` | `'mn' \| 'en' \| 'zh' \| 'ru'` | Идэвхтэй хэл |
| `setLang` | `(l: Lang) => void` | Хадгалж solar-д бичинэ |
| `t` | `(key: TranslationKey) => string` | `getT(lang)` |

**Persistence:** `setLang` нь localStorage-ийн `verno_lang`-д хадгалж дараагийн ачаалалд хадгална.

## 4. Key naming convention

| Prefix | Хүрээ | Жишээ |
|--------|------|-------|
| `menu_*` | Sidebar / nav menu items | `menu_dashboard`, `menu_gl` |
| `tab_*` | HeaderTabs subnav | `tab_gl_entries`, `tab_ar_invoices` |
| `col_*` | StandardTable column header | `col_invoice_num`, `col_amount` |
| `tbl_*` | StandardTable toolbar | `tbl_search`, `tbl_group`, `tbl_no_data` |
| `btn_*` | Бүх товч | `btn_save`, `btn_cancel`, `btn_delete` |
| `dlg_*` | AlertDialog header/body | `dlg_delete_title`, `dlg_post_body` |
| `mdl_*` | Modal header/body | `mdl_bom_create_title` |
| `toast_*` | Toast message | `toast_save_success`, `toast_post_failed` |
| `<module>_*` | Модуль доторх page label | `gl_journal_title`, `ar_dashboard_kpi_total` |
| `err_*` | Error message | `err_required_field`, `err_period_closed` |
| `placeholder_*` | Input placeholder | `placeholder_search_account` |

**Гэрээ:** snake_case. Шинэ key-ийг хэрэглэхийн өмнө **`keys.ts`-д нэмэгдсэн** байх ёстой (TypeScript type-аар compile error-ээр баталгаажна).

## 5. Шинэ key нэмэх workflow

1. **`keys.ts`** — `TranslationKey` union type-д шинэ string literal нэмэх:
   ```ts
   export type TranslationKey =
     | ...
     | 'btn_my_new_action'
   ```
2. **`mn.ts`** — `{ btn_my_new_action: 'Шинэ үйлдэл' }` нэмэх.
3. **`en.ts`** — `{ btn_my_new_action: 'New action' }` нэмэх.
4. **`zh.ts`** — `{ btn_my_new_action: '新动作' }` нэмэх.
5. **`ru.ts`** — `{ btn_my_new_action: 'Новое действие' }` нэмэх.
6. **`i18n.test.ts`** автоматаар бүх 4 хэлд key байгааг шалгана — pass болсон үед merge-д бэлэн.

> CI hook (`.claude/settings.json`-ийн PostToolUse) i18n .ts files-ийн consistency-ийг шалгадаг (advisory).

## 7. Серверийн message i18n

Backend (Express) error message нь анхдагчаар English. Front-д **client-side mapping table** ашиглан орчуулга харуулна:

```ts
const errorKeyMap: Record<string, TranslationKey> = {
  'PERIOD_CLOSED': 'err_period_closed',
  'INSUFFICIENT_PERMISSION': 'err_no_permission',
  'INVALID_ACCOUNT': 'err_invalid_account',
  ...
}

const apiErrorKey = error.response?.data?.code  // backend код
const userMessage = errorKeyMap[apiErrorKey]
  ? t(errorKeyMap[apiErrorKey])
  : (error.response?.data?.message ?? t('toast_generic_error'))
```

> Backend нь `code` field-ыг error response-д **үргэлж** буцаах ёстой (V1.07-д тэрхүү гэрээг хатуужуулна).

## 8. Огноо / тоо / валют formatter

JS native `toLocaleString` нь хэлээр өөр format-тай. Entry нь дараах bias-аар хэрэглэнэ:

| Locale | Огноо | Тоо | Валют |
|--------|-------|-----|-------|
| mn | YYYY-MM-DD (ISO) | 1,234,567.89 | `1,234,567.89 ₮` |
| en | YYYY-MM-DD (ISO) | 1,234,567.89 | `1,234,567.89 ₮` |
| zh | YYYY-MM-DD | 1,234,567.89 | `¥1,234,567.89` (USD-CNY conv үед) |
| ru | DD.MM.YYYY | 1 234 567,89 | `1 234 567,89 ₽` (RUB conv үед) |

> Currency-ийн default нь Mongolian Tugrug (₮). Multi-currency дүн харуулахдаа символыг сүүлд дөрөвт цэгтэй харуулна.

**`amountInWords.ts`** (`lib/amountInWords.ts`) нь зөвхөн Mongolian-д ажиллана; `lang === 'mn'` үед invoice/payslip print-д 'нэг мянга нэг зуун ...' гэх мэт текст үүсгэдэг.
