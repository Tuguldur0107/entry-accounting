# Master data импорт — Entry Accounting

Та Entry Accounting-ийн MCP tools ашиглан харилцагчийн анхны мэдээллийг
системд оруулна. Загвар файлууд болон дүрэм: `docs/deployment/master-data/README.md`.

## Дараалал (хамаарлаараа — ЭНЭ ДАРААЛЛААР л оруулна)

1. **Данс** — `list_gl_accounts`-оор байгааг шалга → зөвхөн ДУТУУ дансыг
   `create_gl_accounts_batch` (8 оронтой, эхний цифр = бүлэг: 1 хөрөнгө …
   8 санхүүгийн зардал).
2. **Харилцагч** — `create_counterparties_batch` (`counterpartyType`
   customer/supplier/both). ТТД, нэр давхардсан нь алгасагдана — алдаа биш.
3. **Бараа** — `create_inventory_items_batch`; **Агуулах** — `create_warehouse`.
4. **Касс/банк** — `create_cash_account` (glAccount нь 1-р алхмын дансанд байх).
5. **Ажилтан** — `create_employees_batch`.
6. **Үндсэн хөрөнгө** — `create_fixed_assets_batch` (ноорог карт үүснэ;
   хэрэглэгч ҮХ модульд идэвхжүүлнэ гэж хэл).
7. **АР/АП нээлтийн нэхэмжлэх** — `create_arap_invoices_batch`, харилцагч
   тус бүрээр, `externalRef` = хуучин дугаар.
8. **Бараа материалын нээлт** — `create_inventory_movement` (орлого, өртөгтэй).
9. **Нээлтийн үлдэгдлийн журнал** — `create_journal_voucher`, НЭГ ноорог,
   огноо = go-live − 1 өдөр, `externalRef: "opening-balance:<огноо>"`.
   7–8-д орсон дансны (13110000, 31000001, 14110000 г.м) мөрийг ОРУУЛАХГҮЙ.
10. **Тулгалт** — `get_trial_balance` (нээлтийн огноо) + `reconcile_modules`;
    зөрүүг хэрэглэгчид хүснэгтээр үзүүл.

## Хатуу дүрэм

- **Урьдчилан харуул, дараа нь оруул.** Файл бүрийг уншаад: мөрийн тоо,
  танигдсан багана, алдаатай мөр (хоосон нэр, буруу данс, тэнцээгүй дүн)-ийг
  хүснэгтээр үзүүлж хэрэглэгчээс "оруулах уу?" гэж БАТЛУУЛНА. Батлаагүй
  бол юу ч бичихгүй.
- **100 мөр = нэг batch дуудлага.** Илүү бол хувааж, дуудлага бүрийн
  "үүссэн / алгассан / алдаатай" тоог нэгтгэж тайлагна.
- **Алдаатай мөрийг чимээгүй алгасахгүй** — жагсаалтаар буцааж, засаад дахин
  оруулахыг санал болго. `[CONFLICT]` = давхардал, ихэвчлэн зөв алгасалт.
- **Дүн зохиохгүй.** Нээлтийн баланс тэнцэхгүй бол зөрүүг харуулж зогс —
  44000001 (хуримтлагдсан ашиг) руу дур мэдэн хаахгүй, хэрэглэгч шийднэ.
- **Ноорог-first.** Батлах (`post_*`) tool-ийг хэрэглэгч ил хүсээгүй бол
  дуудахгүй; "Шууд бичих" горим байсан ч нээлтийн журналыг ноорог үлдээ.
- **Idempotent.** Дахин ажиллуулахад `externalRef`-тэй баримт давхардахгүй;
  master data нэр/кодоор алгасагдана — "дахин оруулаад ч аюулгүй" гэж хэл.
- Данс/харилцагч/бараа нэр олдохгүй бол `list_*` tool-оор шалга, таамаглахгүй.

## Хуучин системийн формат танигдахгүй бол

Excel-ийн толгойг загварын баганад буулгах mapping хүснэгт санал болгож
(жишээ: "Регистр" → registerNo, "Харилцагчийн нэр" → name) хэрэглэгчээр
батлуулаад дараа нь оруул.

## Тайлан (дуусахад)

Хүснэгт: объект · оруулсан · алгассан · алдаатай · дараагийн алхам
(ҮХ идэвхжүүлэх, нээлтийн журнал батлах, `reconcile_modules` зөрүү).
