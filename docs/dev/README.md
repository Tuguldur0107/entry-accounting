# Хөгжүүлэлтийн дүрэм — модуль бүрээр

Үндсэн `CLAUDE.md` нь session бүрд БҮТНЭЭРЭЭ ачаалагддаг тул зөвхөн хөндлөн
дүрэм + модуль бүрийн ХАТУУ дүрмийн хураангуйг агуулна. Дэлгэрэнгүй (урсгал,
файлын жагсаалт, GL бичилт, үл хамаарах тохиолдол) энд модулиар хуваагдсан.

**Дүрэм:**

- Модулийн код хөндөхийн ӨМНӨ тэр модулийн файлыг бүтнээр нь уншина
- Шинэ feature / дүрэм нэмбэл дэлгэрэнгүйг ЭНД, хатуу дүрэм («ХЭЗЭЭ Ч», «ХОРИОТОЙ»,
  «ЗААВАЛ») өөрчлөгдвөл `CLAUDE.md`-ийн хураангуйг ХАМТ шинэчилнэ — хоёр газар зөрөхгүй
- `CLAUDE.md`-д урт жагсаалт, файлын мод, хүснэгт нэмэхгүй — энд бичээд холбоно
- Бизнесийн шийдвэр, санал (proposal), хэрэгжүүлэх гэрээ нь модулийнхоо
  `docs/<модуль>/` хавтсанд хэвээр (`docs/cost/`, `docs/pos/`, `docs/billing/` …)
