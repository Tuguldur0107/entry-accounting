# ТЕГ / ГЕГ-д X-API-KEY хүсэх албан хүсэлт (2026-10-02)

Entry-ийн ТЕГ-ээс ТАТАХ гурван урсгалд операторын түлхүүр хэрэгтэй (`docs/dev/ebarimt-tax-reconcile.md`
§2, §7, §10). Албан хуудас (developer.itc.gov.mn, PosAPI 3.0 баримт 10.2–10.4) хэнээс авахыг заасан:

| Сервис | Юунд | Түлхүүр олгогч | Env |
|---|---|---|---|
| `getSalesTotalData` (10.2) | Татвар төлөгчийн БҮХ борлуулалтын баримт (status 0; нэхэмжлэх status 3) — Entry-тэй тулгалт, НӨАТ тайлангийн өмнөх шалгалт | **ТЕГ — Татвар төлөгчид үйлчлэх газар** (албан тоот) | `ITC_TPI_API_KEY` |
| `getSaleListERP` (10.3) | Татвар төлөгчийн БҮХ худалдан авалтын баримт (регистрээр) — өглөг, авсан НӨАТ-ын тулгалт | мөн адил (НЭГ түлхүүр) | `ITC_TPI_API_KEY` |
| `tpiDeclaration` (10.4) | Хуулийн этгээдийн гаалийн мэдүүлэг — импортын НӨАТ, гаалийн татвар | **ГЕГ — Мэдээллийн технологийн газар** (албан бичиг) | `ITC_CUSTOMS_API_KEY` |

Түлхүүр ирмэгц Railway `entry-accounting` env-д тавина (`docs/deployment/mongolia-network-runbook.md`
§A хүснэгт); харилцагчийн UI-д ХЭЗЭЭ Ч харуулахгүй. Операторын мэдээлэл: Хос Хас Технологи ХХК,
регистр 6596177, ТТД 90201194984, PosAPI posNo 10000878; Монголд байрлах сервер
`ebarimt.chipmo.mn` (43.231.113.138) — ТЕГ IP хязгаарлалт тавьдаг бол энэ хаягийг нэмүүлнэ.

---

## А. ТЕГ — Татвар төлөгчид үйлчлэх газарт (TPI X-API-KEY)

**Хэнд:** Татварын ерөнхий газар, Татвар төлөгчид үйлчлэх газар (хуулбар: posapi@itc.gov.mn).
**Гарчиг:** «Цахим төлбөрийн баримтын системийн TPI сервисийн X-API-KEY олгох тухай»

```text
ТАТВАРЫН ЕРӨНХИЙ ГАЗАР
Татвар төлөгчид үйлчлэх газарт

Хос Хас Технологи ХХК (регистр 6596177, ТТД 90201194984) нь Цахим төлбөрийн
баримтын системийн PosAPI 3.0-ийн «Хэрэглэгчийн систем нийлүүлэгч байгууллага»
(оператор, posNo 10000878) бөгөөд Entry нягтлан бодох бүртгэлийн системээр
(entry.mn) харилцагч татвар төлөгчдийнхөө төлбөрийн баримтыг илгээж байна.

Харилцагч татвар төлөгчид ТЕГ-д бүртгэгдсэн баримтаа өөрийн санхүүгийн
бүртгэлтэй тулгаж, НӨАТ-ын тайлангаа үнэн зөв гаргах зорилгоор developer.itc.gov.mn
порталын «ebarimt-api (TPI)» бүлгийн дараах сервисүүдийг БОДИТ орчинд ашиглах
X-API-KEY олгож өгөхийг хүсье:

  1. POST https://api.ebarimt.mn/api/tpi/receipt/getSalesTotalData
     — татвар төлөгчийн борлуулалтын бүх төлбөрийн баримт (status 0, нэхэмжлэх status 3),
       зөвхөн 01:00–07:00 цагт, өдөрт нэг удаа;
  2. POST https://api.ebarimt.mn/api/tpi/receipt/getSaleListERP
     — татвар төлөгчийн худалдан авалтын (нийлүүлэгчээс олгосон) баримт, регистрээр.

Хэрэглэх зарчим: зөвхөн УНШИХ (ТЕГ-ийн системд юу ч бичихгүй), татвар төлөгч бүр
өөрийн ITC нэвтрэлтээр (auth.itc.gov.mn, client vatps) өөрийн л мэдээллийг татна;
түлхүүр манай серверт л хадгалагдаж, харилцагчид харагдахгүй.

Тодруулахыг хүсэх зүйл:
  - Түлхүүр операторын (манай) түвшинд нэг олгогдох уу, татвар төлөгч бүрд уу;
  - getSaleListERP-ийг охин компанигүй татвар төлөгч өөрийн худалдан авалтдаа
    (subPin хоосон) ашиглах боломжтой эсэх;
  - Татвар төлөгчийн мэдээллийг манай системээр татах зөвшөөрлийг хэрхэн
    бүртгэх вэ (гэрээ, маягт);
  - IP хязгаарлалт тавьдаг бол манай Монголд байрлах сервер 43.231.113.138
    (ebarimt.chipmo.mn)-ийг зөвшөөрөх.

Холбоо барих: <нэр>, <утас>, <и-мэйл>.

Хүндэтгэсэн,
Хос Хас Технологи ХХК
<албан тушаал, нэр, гарын үсэг, тамга>
<огноо>
```

## Б. ГЕГ — Мэдээллийн технологийн газарт (гаалийн мэдүүлгийн X-API-KEY)

**Хэнд:** Гаалийн ерөнхий газар, Мэдээллийн технологийн газар.
**Гарчиг:** «Хуулийн этгээдийн гаалийн мэдүүлэг татах сервисийн X-API-KEY олгох тухай»

```text
ГААЛИЙН ЕРӨНХИЙ ГАЗАР
Мэдээллийн технологийн газарт

Хос Хас Технологи ХХК (регистр 6596177, ТТД 90201194984) нь Entry нягтлан бодох
бүртгэлийн системийг (entry.mn) хөгжүүлж, Цахим төлбөрийн баримтын системийн
PosAPI 3.0-ийн «Хэрэглэгчийн систем нийлүүлэгч байгууллага» (оператор, posNo
10000878) статустай ажилладаг.

Харилцагч хуулийн этгээдүүд импортын гаалийн мэдүүлгээ (гаалийн татвар, онцгой
албан татвар, хураамж, импортын НӨАТ) санхүүгийн бүртгэл, НӨАТ-ын тайлантайгаа
тулгах зорилгоор developer.itc.gov.mn порталын 10.4 «Хуулийн этгээдийн гаалийн
мэдүүлэг татах сервис»-ийг БОДИТ орчинд ашиглах X-API-KEY олгож өгөхийг хүсье:

  POST https://data.ebarimt.mn/rest/e-inventory-service/api/v1/tpiDeclaration
  (Authorization: Bearer — ITC Keycloak; X-API-KEY — Гаалийн ерөнхий газрын)

Хэрэглэх зарчим: зөвхөн УНШИХ, хуулийн этгээд бүр өөрийн ITC нэвтрэлтээр өөрийн
л мэдүүлгийг татна; түлхүүр манай серверт л хадгалагдаж, харилцагчид харагдахгүй;
мэдүүлгийн мэдээлэл нягтлан бодох бүртгэлд автоматаар бичигдэхгүй (зөвхөн тулгалт).

Тодруулахыг хүсэх зүйл:
  - Түлхүүр операторын түвшинд үү, хуулийн этгээд бүрд үү; хуулийн этгээдийн
    зөвшөөрлийг хэрхэн бүртгэх вэ;
  - Туршилтын орчны хост (data.ebarimt.mn-ээс тусдаа бол) ба туршилтын түлхүүр;
  - dclrDate талбарын цагийн бүс (+0000 — UTC эсвэл Улаанбаатарын цаг);
  - IP хязгаарлалт тавьдаг бол Монголд байрлах сервер 43.231.113.138
    (ebarimt.chipmo.mn)-ийг зөвшөөрөх.

Холбоо барих: <нэр>, <утас>, <и-мэйл>.

Хүндэтгэсэн,
Хос Хас Технологи ХХК
<албан тушаал, нэр, гарын үсэг, тамга>
<огноо>
```
