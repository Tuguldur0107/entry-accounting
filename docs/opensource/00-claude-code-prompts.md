# Claude Code-д өгөх бэлэн prompt-ууд

Фаз бүрд нэг prompt. **Хуулаад шууд ашиглана.** Дараах дүрмийг мөрд:

- **Нэг session = нэг фаз.** Дундаас нь өөр ажил бүү хольж өг
- Claude Code төлөвлөгөө гаргаад чамаас зөвшөөрөл асуусны ДАРАА кодлуулна —
  төлөвлөгөөг уншаад ойлгохгүй зүйл байвал асуу, тэр чинь сургалт
- Фаз 01-ийн өмнө **DB backup** (Railway snapshot эсвэл `pg_dump`) —
  үүнийг Claude Code биш ЧИ хийнэ
- Session дундаа гацвал: `/compact` хийлгэх эсвэл шинэ session нээгээд
  «docs/opensource/XX-...md-г унш, өмнөх session ийм газар зогссон:
  [тайлбар]. Үргэлжлүүл» гэж эхлүүл

---

## Фаз 01 — Multi-tenancy

```
Эхлээд CLAUDE.md-г, дараа нь docs/opensource/01-multi-tenancy.md спекийг
бүрэн унш. Мөн lib/db/schema.ts, lib/auth.ts, lib/periods/guard.ts
файлуудыг судал.

Дараа нь надад үе шаттай төлөвлөгөө гаргаж өг: ямар дарааллаар, ямар
файлуудад, ямар өөрчлөлт хийхээ, migration-ий rollback төлөвлөгөөтэй нь.
Би батлахаас өмнө код бүү бич.

Батлагдсаны дараа спекийн шатуудыг дагаж хэрэгжүүл. Шат бүрийн дараа
build + тест ажиллуулж, надад товч тайлагнаад дараагийн шат руу ор.
Дуусахдаа спекийн "Хүлээн авах шалгуур" бүрийг нэг бүрчлэн шалгаж
үр дүнг хүснэгтээр үзүүл, docs/opensource/README.md-ийн статусыг шинэчил.

Санамж: Би DB backup хийсэн. Migration SQL-ийг эхлээд надад үзүүлж
байж ажиллуул.
```

## Фаз 02 — custom/ өргөтгөлийн давхарга

```
Эхлээд CLAUDE.md-г, дараа нь docs/opensource/02-custom-extension-layer.md
спекийг бүрэн унш. Мөн lib/ai/tools.ts-ийн бүтэц (эхний 200 мөр +
tool бүртгэлийн хэсэг), lib/grid/columnTypes.ts, lib/actions/gl.ts-ийн
post үйлдлийг судал.

Үе шаттай төлөвлөгөө гаргаж надаар батлуул, дараа нь хэрэгжүүл.
Гол шалгуур: (1) хоосон custom/-тай систем яг өмнөх шигээ ажиллана,
(2) demo-barilga багцыг бүртгэхэд tool нь чат болон MCP хоёуланд гарч
ирнэ, (3) hook нь journal balance зэрэг байгаа guardrail-уудыг тойрч
ЧАДАХГҮЙ гэдгийг тестээр батал.

Дуусахдаа "Хүлээн авах шалгуур"-аа шалгаж, custom/README.md,
custom/CLAUDE.md хоёрыг бичиж, docs/opensource/README.md статусыг шинэчил.
```

## Фаз 03 — Лиценз + repo бэлтгэл

```
docs/opensource/03-licensing-and-repo-prep.md спекийг бүрэн унш.

Дараах дарааллаар ажилла:
1. gitleaks (байхгүй бол суулга) бүх git түүхэн дээр ажиллуулж үр дүнг
   надад тайлагна — нууц олдвол ЗОГСООД надад хэл
2. LICENSE.md (FSL-1.1-Apache-2.0 албан текст — getsentry/fsl.software
   repo-гоос), LICENSE-FAQ.md (монголоор, спекийн хүснэгтээр),
   CONTRIBUTING.md, CLA.md, SECURITY.md, .env.example үүсгэ
3. Гадны хүнд зориулсан шинэ README.md бич — quickstart хэсгийг нь
   бодитоор шалгах заавартай нь
4. git ls-files-ийн 482 файлыг хянаж дотоод/хувийн шинжтэйг нь хүснэгтээр
   надад үзүүл — нээх/хаах шийдвэрийг би гаргана
5. knowledge/-ийн 100 файлыг нээх / CC-BY-NC / хаалттай гэж ангилсан
   санал гаргаж надад үзүүл — би батална
6. docs/opensource/launch-checklist.md бич

4, 5-ын шийдвэрийг надаас асуулгүй өөрөө бүү гарга.
```


## Нэмэлт: аль ч үед хэрэг болох жижиг prompt-ууд

**Фаз дуусгасны дараа шалгуулах (өөр session-д):**

```
docs/opensource/XX-...md спекийн "Хүлээн авах шалгуур" хэсгийг унш.
Сая хийгдсэн өөрчлөлтүүд (git log-ийн сүүлийн commit-ууд) эдгээр
шалгуурыг ҮНЭХЭЭР хангаж буйг код уншиж, тест ажиллуулж хөндлөнгөөс
шалга. Хангаагүй зүйл олдвол жагсааж өг — засах шаардлагагүй, зөвхөн ол.
```

**Спек өөрчлөх хэрэгтэй болбол:**

```
docs/opensource/XX-...md спекийн [хэсэг]-ийг ингэж өөрчилье: [шалтгаан].
Эхлээд спек файлыг засаж, өөрчлөлтийн шалтгаан тэмдэглэ, дараа нь кодоо
спектэй нийцүүл.
```
