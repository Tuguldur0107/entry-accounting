## Хийх ажил

### Шат 1 — Лицензийн файлууд

1. `LICENSE.md` — **FSL-1.1-Apache-2.0** албан ёсны текст.
   https://github.com/getsentry/fsl.software repo-гийн
   `FSL-1.1-Apache-2.0.template.md`-ээс ав, `{licensor}`-т эзэмшигчийн
   нэр. Текстийг ӨӨРЧЛӨХГҮЙ — өөрчилбөл FSL гэж нэрлэх эрхгүй болно
2. `LICENSE-FAQ.md` — монголоор, энгийн хэлээр. Гол хүснэгт:

   | Тохиолдол | Лиценз |
   |-----------|--------|
   | Компани өөрийн бүртгэлдээ ашиглана (хэдэн салбар/охин компанитай ч) | Үнэгүй |
   | Нягтлан фирм клиентийн дата оруулна, клиент СИСТЕМД НЭВТРЭХГҮЙ | Үнэгүй |
   | Клиент өөрөө нэвтэрч ашиглана / клиентэд төлбөртэй хандалт өгнө | Partner лиценз |
   | Entry-г (өөр нэрээр ч) гуравдагч этгээдэд SaaS/бүтээгдэхүүн болгон санал болгоно | Partner лиценз |
   | 2 жил өнгөрсөн хувилбар | Apache-2.0 — бүрэн чөлөөтэй |

   + Partner лицензийн холбоо барих хаяг
3. `CONTRIBUTING.md` — монгол + англи товч: PR урсгал, CLA шаардлага,
   commit хэв маяг, `custom/` vs core ялгаа
4. `CLA.md` — Individual CLA текст (Apache ICLA-д суурилсан энгийн
   хувилбар): contributor нь оруулсан кодоо лицензлэх өргөн эрхийг
   licensor-т олгоно (ирээдүйд дахин лицензлэх эрхийг хадгална)
5. `SECURITY.md` — аюулгүй байдлын цоорхойг хаана мэдэгдэх (email),
   нийтэд ил болгохын өмнө 90 хоног хугацаа өгөх хүсэлт

### Шат 2 — Repo ариун цэвэр

1. **Нууц скан:** `gitleaks detect --source . --log-opts="--all"`
   (эсвэл trufflehog) — түүх бүхэлдээ. Юу ч олдвол: нууцыг СОЛИХ
   (rotate) нь үндсэн арга; түүх цэвэрлэх шийдвэрийг эзэнд үлдээ
2. `.env.example` үүсгэ — бүх шаардлагатай хувьсагч placeholder утгатай,
   тайлбартай (DATABASE_URL, AUTH_SECRET, AI түлхүүрүүд...)
3. `.gitignore` шалга: `.env*` (`.env.example`-аас бусад), `*.pem`,
   dump файлууд
4. Tracked 482 файлыг эргэн хянах хүснэгт гарга (`git ls-files`) —
   дотоод/хувийн шинжтэй файлуудыг тэмдэглэж эзэнд шийдвэрлүүл:
   `REVIEW-PROGRESS.md`, `FA_MODULE_PLAN.md`, `INVENTORY_COSTING_PLAN.md`,
   лого эх файлууд г.м. — нээх үү, устгах уу, private үлдээх үү
5. `knowledge/` аудит: файл бүрийг гурав ангил —
   (а) нээх (IFRS/татварын нийтийн лавлагаа),
   (б) CC-BY-NC-ээр нээх (сургалтын материал),
   (в) хаалттай үлдээх (дотоод шийдвэр, арилжааны нууц).
   Ангиллын жагсаалтыг эзэнд батлуулж байж хөдөл
