- Session бүр ЗӨВХӨН төлөвлөгөө бичнэ, код засахгүй. Төлөвлөгөөг хүн баталсны дараа хэрэгжүүлэлт эхэлнэ.

- Тусдаа git branch (эсвэл worktree) ашигла.
- Гаралт монголоор, техник нэр томьёо англиар байж болно.
- Буцаалтын бичилтийг «буцаалт» гэж нэрлэ, «сторно» гэж бичихгүй.
- Хоёрдмол зүйл гарвал таамаглахгүй, «Шийдвэр шаардсан асуултууд» хэсэгт бичээд асуу.
