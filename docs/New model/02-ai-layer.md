# Session 2 — AI-д зориулсан MCP давхарга

# Даалгавар: entry MCP-г хэрэглэгчийн AI (Claude, ChatGPT) бие даан ашиглах чадвартай болгох төлөвлөгөө

Зорилго: entry ашигладаг хэрэглэгч системийн зааврыг мэдэхгүй байсан ч өөрийн Claude/ChatGPT-д MCP холбоод "нийлүүлэгчээс бараа авлаа", "сараа хаамаар байна" гэхэд AI нь зөв дарааллаар, алдаагүй гүйцэтгэдэг болгох. Энэ давхаргыг "Entry AI skill" гэж нэрлэнэ.

**Хамрах хүрээ:** зөвхөн MCP server-ийн код, tool description, workflow guide, MCP instructions/prompts/resources. Цөмийн нягтлан бодох логик, DB, UI-д ХҮРЭХГҮЙ (тэдгээрийг өөр session хийж байгаа).

**Ажлын горим:** эхлээд судалж `PLAN-ai-layer.md` бичнэ. Зөвхөн текст/description/markdown өөрчлөлт бол (кодын логик өөрчлөхгүй, миграцигүй) төлөвлөгөөнд "шууд хийж болно" гэж тэмдэглэ, би баталсны дараа хэрэгжүүлнэ. Тусдаа branch дээр ажилла.

## 1. Судалгаа

а) MCP server хэрхэн бүтээгдсэн бэ (framework, файлууд)? Tool description-ууд хаана тодорхойлогддог — код дотор уу, тусдаа файлд уу?

б) Одоогийн 111 tool-ийн description-ийг тус бүрд нь дараах шалгуураар үнэл, хүснэгтээр гарга:
- Урсгал дахь байрлалаа заасан уу ("энэ бол X урсгалын N-р алхам, дараа нь Y")
- Хэзээ ашиглахгүйг заасан уу
- Ноорог/батлагдсан/буцаах гэсэн төлөвийн нөлөөг тайлбарласан уу
- Түгээмэл алдаа, түүний засварыг заасан уу
- Буцаахад хэцүү үйлдэл (устгах, батлах, үе хаах) гэдгийг анхааруулсан уу

в) `get_workflow_guide`-ийн 8 урсгалын агуулгыг унш. Ямар нийтлэг ажил дутуу байна (payroll, vat_return, year_end_closing, bank_import, inventory_count, landed_cost, fx_revaluation, буцаалт гэх мэт)?

г) MCP server одоо instructions, prompts, resources дэмждэг үү? Хэрэглэгч tenant тус бүрийн MCP холболт (API key) хэрхэн үүсдэг вэ?

д) ChatGPT-ийн remote MCP дэмжлэг instructions/prompts/resources-ийг хэр дэмждэгийг баримтаас шалга (web search хэрэглэ). Claude болон ChatGPT хоёулан дээр ажиллах ёстой.

## 2. Санал болгох өөрчлөлт

1. **Tool description-ийн стандарт загвар** гаргаж, бүх tool-д хэрэглэ. Загвар: нэг мөр зорилго → урсгал дахь байрлал → ноорог/батлах нөлөө → хэзээ ашиглахгүй → анхааруулга. Description урт хэмжээ context идэх тул 400 тэмдэгтээс хэтрүүлэхгүй, дэлгэрэнгүйг get_workflow_guide-д үлдээ.

2. **get_workflow_guide-ийг өргөтгө**: дутуу урсгалуудыг нэм; workflow параметргүй дуудахад бүх урсгалын жагсаалтыг нэг мөр тайлбартай буцаадаг болго; урсгал бүрт "түгээмэл алдаа ба засвар" хэсэг нэм.

3. **MCP server instructions** бич: холбогдох үед AI-д автоматаар очих 300–500 үгийн заавар. Агуулга: entry-ийн үндсэн зарчим (ноорог → батлах, батлагдсан баримтыг засахгүй зөвхөн буцаалт, хаагдсан үе), олон алхамт ажлын өмнө get_workflow_guide заавал дуудах, буцаахад хэцүү үйлдлийн өмнө хэрэглэгчээс баталгаажуулах, монголоор харилцах, «буцаалт» гэх нэр томьёо.

4. **MCP prompts**: month_end_close, new_company_setup, payroll_run, vat_return, fix_discrepancy, year_end гэсэн бэлэн prompt-ууд. Prompt бүр хэрэглэгчээс ямар мэдээлэл асуух, ямар tool дарааллаар дуудахыг заана.

5. **MCP resources**: `entry://guide/tax/vat`, `entry://guide/tax/ndsh`, `entry://guide/tax/haoat`, `entry://guide/ifrs/{сэдэв}`, `entry://guide/chart-of-accounts`, `entry://guide/terminology` гэх мэт. Сэдэв бүр жижиг (1–2К үг), markdown файлаас уншигдана, хуулийн тоон утга (НДШ-ийн хязгаар, ХАОАТ-ын шатлал) хүчинтэй огноотой. **Тоон утгыг таамаглаж бүү бич** — «[ШАЛГАХ: ___]» гэж тэмдэглэ, би бөглөнө. Энэ хэсэг Session 5-ийн мэдлэгийн сантай нийлнэ — тэнд `search_knowledge` / `get_knowledge` гэсэн 2 tool нэмэгдэхийг тооц.

6. Эдгээр нь ChatGPT дээр ажиллахгүй бол (instructions/prompts дэмжихгүй бол) fallback: `get_started` tool нэмж, ижил агуулгыг буцаадаг байх.

## 3. Гаралт

`PLAN-ai-layer.md`: судалгааны хүснэгт, шинэ description-ийн загвар, 3 tool-ийн жишээ description (өмнө/дараа), instructions-ийн бүрэн эх, prompt-уудын жагсаалт, resources-ийн бүтэц, хэрэгжүүлэх дараалал. Монголоор, нэр томьёо англи байж болно.
