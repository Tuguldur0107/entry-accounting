# Даалгавар: хэрэглэгчид UI-г заадаг get_ui_guide tool-ийн төлөвлөгөө

Зорилго: хэрэглэгч "нэхэмжлэх яаж үүсгэх вэ", "сараа яаж хаах вэ" гэж өөрийн Claude/ChatGPT-ээс асуухад AI нь entry-ийн UI дээр алхам алхмаар (цэс → дэлгэц → товч → талбар) зааж, шууд тухайн дэлгэц рүү очих линк өгдөг болгох.

**Хамрах хүрээ:** React frontend-ийн route/бүтэц судлах, `docs/ui-guide/` хавтасны markdown зааврууд, MCP-д нэг шинэ tool. Нягтлан бодох логик, DB-д ХҮРЭХГҮЙ. Тусдаа branch.

**Ажлын горим:** судалж `PLAN-ui-guide.md` бичнэ. Код засахгүй.

## 1. Судалгаа

а) Frontend-ийн бүх route-ийн жагсаалт (зам, дэлгэцийн нэр, ямар модуль). Tenant-ийн base URL хэрхэн бүтээгддэг?

б) Дэлгэц бүр дээрх гол үйлдлүүд (товч, форм, талбар) — эх кодоос уншиж дэлгэц бүрээр товч жагсаа.

в) Одоо ямар нэг help, tooltip, onboarding байгаа эсэх?

г) Дэлгэцүүдэд тогтвортой `data-help-id` эсвэл route нэр өгөх боломж — UI засварласан ч заавар эвдрэхгүй байх арга.

## 2. Санал

1. **docs/ui-guide/ бүтэц**: сэдэв тус бүр нэг markdown (жишээ: `ar-invoice-create.md`, `month-end-close.md`, `new-company-setup.md`). Файл бүр: зорилго, урьдчилсан нөхцөл, алхмууд (дэлгэцийн зам + үйлдэл), route линк, түгээмэл алдаа, холбоотой MCP tool. **get_workflow_guide-ийн урсгалуудтай нэг нэгээр тааруулж, хоёр зааврын дэс дараалал зөрөхгүй байх.**

2. **get_ui_guide(topic?) MCP tool**: topic-гүй дуудвал сэдвүүдийн жагсаалт; topic өгвөл markdown-ийг буцаана + tenant-ийн бодит route линк (жишээ: `https://{tenant}.entry.mn/ar/invoices/new`). Tenant-ийн домайныг MCP холболтын контекстээс авна.

3. Ирээдүйд: дэлгэц бүрт "AI-аас асуух" товч, эсвэл URL-д `?help=topic` параметр — заавал биш, санал болгоод үлдээ.

4. Зааврыг эхний ээлжинд **10–15 хамгийн түгээмэл сэдвээр** хязгаарла, жагсаалтыг санал болго.

## 3. Гаралт

`PLAN-ui-guide.md`: route хүснэгт, сэдвүүдийн жагсаалт, 2 сэдвийн бүрэн жишээ заавар, tool-ийн тодорхойлолт, хэрэгжүүлэх алхам. Монголоор.
